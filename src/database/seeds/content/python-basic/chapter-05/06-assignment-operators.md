# Assignment Operators

Assignment operators store values in variables.

The most common assignment operator is `=`.

```python
score = 10
```

This stores `10` in the variable `score`.

---

## Updating a Variable

You can update a variable using its current value.

```python
score = 10
score = score + 5
print(score)
```

Output:

```text
15
```

---

## Shortcut Assignment Operators

Python provides shortcuts.

```python
score += 5
score -= 2
score *= 3
score /= 2
```

These are shorter ways to update a variable.

---

## Example

```python
coins = 0
coins += 10
coins += 5

print(coins)
```

Output:

```text
15
```

---

## Summary

Assignment operators store and update values. Shortcuts like `+=` are common in real Python code.
