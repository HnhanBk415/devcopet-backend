# Assignment Operators

Assignment operators store values in variables. Shortcut assignment operators make updates shorter and clearer.

---

## Learning Goals

By the end of this lesson, you should be able to:

- `=` assigns a value.
- Variables can be updated based on their current value.
- Shortcut operators make updates concise.

---

## 1. Basic assignment

Use `=` to store a value in a variable.

```python
score = 10
print(score)
```

Output:

```text
10
```

---

## 2. Updating variables

You can update a variable using its current value.

```python
score = 10
score = score + 5
print(score)
```

Output:

```text
15
```

---

## 3. Shortcut assignment

Operators like `+=`, `-=`, and `*=` are shorter ways to update variables.

```python
score = 10
score += 5
score *= 2
print(score)
```

Output:

```text
30
```
