# Arithmetic Operators

Arithmetic operators let you calculate with numbers. They are used for totals, scores, prices, measurements, and many other numeric tasks.

---

## Learning Goals

By the end of this lesson, you should be able to:

- Arithmetic operators perform math.
- Variables can be used in expressions.
- Calculation results can be stored for later use.

---

## 1. Basic arithmetic

Python supports addition, subtraction, multiplication, and division.

```python
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 / 3)
```

Output:

```text
13
7
30
3.3333333333333335
```

---

## 2. Use variables in expressions

Operators work with variables as well as literal numbers.

```python
price = 15
quantity = 3
print(price * quantity)
```

Output:

```text
45
```

---

## 3. Expressions can be stored

You can store a calculation result in another variable.

```python
subtotal = 80
tax = 8
total = subtotal + tax
print(total)
```

Output:

```text
88
```
