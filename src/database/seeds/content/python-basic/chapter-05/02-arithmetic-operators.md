# Arithmetic Operators

Arithmetic operators are used for math.

Common arithmetic operators include:

| Operator | Meaning | Example |
|---|---|---|
| `+` | Addition | `3 + 2` |
| `-` | Subtraction | `3 - 2` |
| `*` | Multiplication | `3 * 2` |
| `/` | Division | `3 / 2` |
| `//` | Floor division | `3 // 2` |
| `%` | Modulo | `3 % 2` |
| `**` | Exponent | `3 ** 2` |

---

## Example

```python
print(10 + 5)
print(10 - 5)
print(10 * 5)
print(10 / 5)
```

Output:

```text
15
5
50
2.0
```

---

## Summary

Arithmetic operators allow Python to calculate values. They are used in almost every kind of program.
